# ADINA | Возможности и AI

Русскоязычный двухстраничный сайт в бордово-кремовом оформлении.

## Как посмотреть

1. Распакуйте ZIP полностью в одну папку.
2. Откройте `index.html` в браузере.
3. Страница автоматизации CV находится в `cv.html`.

Все файлы (`index.html`, `cv.html`, `style.css`, `config.js`, `app.js`) должны находиться в одной папке.

## Как редактировать без навыков программирования

Откройте `config.js` в Блокноте или редакторе кода. Меняйте только значения внутри кавычек, не удаляя кавычки и запятые:

- `freeChannel` , бесплатный Telegram-канал;
- `paidClub` , ссылка на платный клуб;
- `contact` , **личный** Telegram для связи;
- `cvPrice` , стоимость продукта;
- `cvAvailable` , `false` пока покупка не активирована, `true` после подтверждения готовности продукта и добавления личной ссылки;
- `cvIncludes` , пункты комплектации продукта;
- `intro`, `brand`, `tagline` , текст главной страницы.

Для изменения подробного текста продающей страницы откройте `cv.html` в редакторе кода; для изменения главной страницы , `index.html`. Цвета и размеры находятся в `style.css`. Сохраните файл и обновите страницу браузера.

**Важно:** информация о комплектации на сайте описывает планируемый продукт. Перед продажей проверьте наличие и работоспособность каждого шаблона, инструкции и видео. На сайте нет встроенной оплаты, серверной обработки данных или реального AI-движка , это информационный лендинг.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из папки сайта (не ZIP).
3. В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
4. Дождитесь появления адреса сайта. Бесплатный адрес обычно имеет вид `https://USERNAME.github.io/REPOSITORY/`.

После обновления файлов на GitHub сайт обновится автоматически после сборки. Публичный репозиторий означает, что исходные тексты, ссылки и код доступны всем; не храните в них пароли, личные документы или данные клиентов.


## Новая страница консультации (v4)

- `consultation.html` , продающая страница индивидуального разбора за €50 / 60 минут.
- `consultation.js` , логика анкеты.
- В `config.js` настройте `consultationPrice`, `consultationMinutes`, `contact` и `consultationFormEndpoint`.
- ВАЖНО: GitHub Pages , статический хостинг. Без настройки `consultationFormEndpoint` форма **не отправляет** заявки автоматически. Она лишь формирует текст, который клиент может скопировать и отправить вручную в Telegram. Не публикуйте сайт с обещанием автоматической отправки до настройки и теста.
- Для автоматических заявок можно подключить сервис форм с HTTPS endpoint (например, Formspree) и его уведомления; для доставки прямо в Telegram нужен отдельный защищённый серверный обработчик/бот. Никогда не вставляйте токен Telegram-бота в `config.js` или публичный JS.
- Иллюстрации на странице , авторские декоративные CSS-композиции, не фотографии реальных программ.
